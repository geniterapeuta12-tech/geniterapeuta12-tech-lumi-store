# Lumi Store

Loja oficial da Lumi Clínica para versões, atualizações, recursos e downloads para computador e celular.

## Recursos atuais

- Site responsivo para computador e celular
- Catálogo de versões Windows e Mobile
- Histórico de atualizações
- Área de recursos e complementos
- Página Minha Lumi
- Aplicativo instalável PWA
- Cache offline da loja
- SEO básico com sitemap e robots.txt
- Publicação automática pelo GitHub Pages
